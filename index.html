    End-to-End LLM Processing Pipeline

    How human language transforms into machine-readable mathematical representations

    Stage 1 📝

    Raw Text Input

    Natural human text consisting of characters, words, sentences, punctuation, and Unicode strings.

    String / UTF-8
    Stage 2 ✂️

    Tokenization

    Byte-Pair Encoding (BPE) segments words into frequent subword units, preserving morphology and handling rare words gracefully.

    BPE Subwords
    Stage 3 🔢

    Vocabulary IDs

    Tokens are mapped to arbitrary integer indices in the model's fixed dictionary (e.g. GPT-2's 50,257 vocabulary entries).

    Discrete Integers
    Stage 4 🌐

    Vector Embeddings

    Token IDs are looked up in an embedding matrix ($\mathbf{E} \in \mathbb{R}^{V \times D}$), producing dense continuous vectors that capture semantic meaning.

    384-D / 768-D Vectors
    Stage 5 🧠

    Transformer Layers

    Multi-Head Self-Attention allows tokens to attend to each other, updating their vector representations based on the surrounding context.

    Attention / Feed-Forward
    Stage 6 🎯

    Output Prediction

    Final layer projects contextual vectors through an LM head and Softmax to predict the probability distribution over all vocabulary tokens.

    Softmax Probabilities
